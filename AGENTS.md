# Repository instructions

## Contribution attribution

Do not identify Claude, Codex, OpenAI, Anthropic, or any other AI tool as an
author or contributor in commits, commit trailers, pull request descriptions,
or comments. Do not add "Generated by" messages or similar AI attribution.
Preserve the human contributor's configured Git identity as the commit author.
